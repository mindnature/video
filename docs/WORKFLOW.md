# 七步制作管线与质量关口

1. **Idea / 剧本**：一句创意，选 `handcraft` 或 `story`，生成 `project.json`。对 handcraft 给出每一镜真实工序；对 story 写好视觉笑点及角色动机。`draft` 是可选 LLM 助手，非强制依赖。
2. **Storyboard**：锁定场景、人物常量、机位、`beats` 及配音起止；内容字段结构可用 JSON 校验。
3. **Shot prompts**：`plan` 批量生成独立镜头提示词，要求真实工艺、合理声画、画面不自动长出文字。演员跨镜描述按 `characters` 固定。
4. **Video generation**：Google Flow 由人审定参数和生成额度。`flow-assist` 仅是选配的 CDP 文本框辅助。把真实下载的视频逐镜 `ingest`，绝不覆盖旧版本。
5. **Sound**：`voice_lines.csv` 记录台词起止；可由外部 VoxCPM2 / TTS 生成，逐条导入，再在 render 阶段混音。若涉及声音克隆须取得相关主体授权。
6. **Post**：FFmpeg 标准化尺寸、帧率、尾帧补齐、裁剪、拼接，选择 SRT 烧录或保留外部字幕文件。
7. **QA**：`qa` 做可自动完成的技术核验；AI/人工必须再逐镜检查材质、动作、人物一致性、嘴形、字幕、黑帧、异响和叙事效果。

## 当前实现与计划方向

已实现：离线项目模板、结构化镜头、提示词、配音时间轴/SRT、可选 LLM 草拟、Flow 网页填词辅助、素材哈希版本归档、FFmpeg 拼接/混音、技术 QA、CI 测试。

未实现：Flow 网站无监督批量自动生成与下载、内建 VoxCPM2 / Whisper 推理、唇形视觉检测、智能目标追踪、动态监控 HUD、基于逐帧语义模型的画面异常检测、视频平台一键发布。这些需要针对版本、环境与授权做独立集成，不能仅靠提示词宣称完成。
